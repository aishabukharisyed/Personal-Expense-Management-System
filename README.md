# Personal Expense Tracker (C++)

A beginner-friendly C++ project developed using Object-Oriented Programming (OOP).

## About the Project

The Personal Expense Tracker is a console-based application designed to help users manage their income and expenses.

The goal of this project is to practice C++ programming and understand how OOP concepts are used in real-world applications.

## Current Features

- Create a transaction object.
- Enter a transaction amount.
- Display transaction details.

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Classes and Objects
- Functions

## Concepts I'm Learning

- Encapsulation
- Constructors
- Arrays
- Loops and Conditional Statements
- File Handling
